Rapidity iPhone testing

Rapidity is a spaceship operations simulator built accessibility-first: the whole game is instruments, and it must be fully playable with a screen reader and no screen. Two things need testing on real iPhones, with VoiceOver running as you normally have it.

  1. Test 1 — a live gauge: how chatty should an instrument be? Six questions.
  2. Test 2 — sound and the mute switch: does muting the phone kill the game's audio? Six questions. This one decides real architecture.
  3. Report form: autosaves as you type; one button turns it into plain text to send to Jeremy.

About 20 minutes. Blunt is useful — "works, but I'd hate it after an hour" is exactly the kind of answer this needs.

Begin with Test 1. Thanks.

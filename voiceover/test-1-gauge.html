Questions (answer on the report form)

  1. 1.1 — Before starting the drift, read the gauge with the VO cursor. What does VoiceOver say, as close to word for word as you can?
  2. 1.2 — Start the drift and return to the gauge a few times over a minute, however you normally move. Current value each time, or stale? Any difference between keyboard focus and the VO cursor?
  3. 1.3 — Chatty for a minute while you read elsewhere on the page. Keep up, fall behind, or flood? Livable on a real panel?
  4. 1.4 — Alerts only, until the value crosses 30 a few times (give it two or three minutes). Announced reliably, both directions?
  5. 1.5 — Back to Quiet, drift still running. Silent, as it should be?
  6. 1.6 — The design bet: instruments stay quiet, you query on demand, only genuine alerts speak. Right bet for hours of play?
